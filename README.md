#  User List App (React Native + Expo)

A simple mobile application built with React Native and Expo that fetches users from an API, displays them in a list, and shows detailed information on a separate screen using React Navigation.



#  Features

- Fetch users from external API
- Display users in a list (FlatList)
- Navigate to detail screen on click
- Pass data between screens
- Clean and simple UI
- Built with React Navigation (Stack Navigator)





#  Screens

# Home Screen
Displays list of users fetched from API.

# Detail Screen
Shows selected user details (name, email, phone).



# Tech Stack

- React Native
- Expo
- React Navigation
- JavaScript / TypeScript
- REST API (JSONPlaceholder)
